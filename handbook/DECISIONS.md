# Решения

Новые сверху. Формат: дата — решение — почему.

- **2026-10-28** — Миша: строим по готовому концепту на холсте пятью этапами (каркас → редактор рилса → пост и карусель → стратегия и план → команда); одна дизайн-система (Manrope, нейтральная, чёрная главная кнопка). Без таймлайна, свободного дизайна слайдов и автопубликации пока. — Разбор «что реально» на странице «Редакторы».

- **2026-10-28** — Миша и Сева — равные партнёры: каждый сам ставит задачи, решает интерфейс (включая ★ доски), сливает без ревью и выкладывает на прод через ветку `prod`; решения пишем сюда с именем. — Чтобы не ждать согласований друг друга.

- **2026-10-28** — Постоянные адреса через именованный туннель Cloudflare на mygudauri.org: `reels.` — студия, `stage-reels.` — стенд. — Временные адреса менялись при каждом перезапуске.

- **2026-10-27** — Общий стенд на сервере владельца: отдельный пользователь, демо-данные, сам обновляется из `main`. — Соавторы смотрят слитое вместе, не трогая рабочий бот.

- **2026-10-27** — Работаем через репозиторий: справочник в `handbook/`, задачи и вехи на GitHub, ветка + pull request на задачу, выкладка на сервер только у владельца. — Чтобы дизайнеры и разработчики со своими Claude работали в одном контексте.
- **2026-10-27** — Этапы по созвону: 1 — сырьё → варианты → календарь (посты и карусели), 2 — рилсы и серии, 3 — автоматика. — Сначала то, без чего команда не может публиковать; рилсы из случайных видео нестабильны.
- **2026-10-27** — Роли на старте: редактор (он же админ), автор, ведущий. Авторы живут только в боте. — Маленькой команде не нужны шесть ролей; учителю не нужно ставить приложение.
- **2026-10-27** — Команда — не отдельный режим, а ещё одна колонка настроек на тех же уровнях каскада. — Одна структура для одного автора и для школы.
- **2026-10-27** — Контент делается сериями: рубрика ⊃ серия-шаблон ⊃ выпуски, выпуски пачками. — Не придумывать каждый ролик с нуля; уже так делали стихийно (цены 02→10→13).
- **2026-10-27** — Каскад настроек: проект → канал → формат → рубрика → серия → выпуск; ниже строже, 🔒 нельзя переопределить. — Каждый выпуск — чат, который сам знает свои правила.
- **2026-10-27** — Интерфейс: три раздела (Работа · План · Проект), всё вокруг чата, панели справа. — Как у бота в Телеграме, только с экраном.
- **2026-10-27** — Агент веб-студии работает по списку разрешений, без «пропуска вопросов»; отдельный пользователь на сервере. — Страница в интернете не должна давать произвольный доступ к серверу.
- **2026-10-27** — Хранение версий: текущая целиком, прошлая — лёгкая копия, старше — кадр и снимок кода. — Диск сервера 30 ГБ.
- **2026-10-27** — Сервер — Timeweb Cloud, Амстердам, оплата в рублях. — Claude недоступен с российских адресов; западные облака требуют иностранную карту.
