# Запуск: первый платящий клиент

Черновик плана, 28.10.2026. Продукт — для людей и бизнесов вне РФ; «Школа» и «Летняя школа» на холсте — примеры, а не заказчик. Цены и лимиты — в скобках `[…]`: их решают Миша и Сева.

## Что продаём на этапе 1

Минимум, за который платят: **посты и ролики по шаблонам, всё через Телеграм** (бот + мини-приложение), веб-студия — для тех, кто хочет экран побольше.

1. Человек или участник команды скидывает фото, видео, голосовое в бот → «Понял так» → один вопрос, если без него нельзя.
2. Система делает 2–3 варианта поста (Телеграм длинный, Instagram короткий) и карусель по 5 шаблонам слайдов.
3. Редактор выбирает вариант в боте или мини-приложении → в план на дату → публикация (Телеграм — сами, Instagram — Graph API или «скачать и выложить»).
4. Ролики: материал → шаблон рубрики (Т1) → черновик → правки комментариями в мини-приложении (SE1–SE5) → «Собрать vN».
5. Автору — «Ваш пост вышел».

Не входит в этап 1: статистика и выводы, свободный монтаж, трендовый звук Instagram (через API не добавить), другие площадки кроме Телеграма и Instagram.

## Режимы, тарифы и уровни доступа

Три независимые оси. Сейчас в коде есть только третья.

**1. Режим — как устроен клиент.** Меняет интерфейс, а не цену.

| Режим | Кто | Что видно |
|---|---|---|
| Один | эксперт, блогер, маленький бизнес | нет Входящих, заданий людям и согласования |
| Команда | школа, клиника, студия, магазин | участники, задания, входящие, согласующий по ссылке |
| Агентство | SMM-специалист с несколькими клиентами | несколько проектов, переключатель, сводка по проектам |

**2. Тариф — какие функции включены и сколько.**

| Функция | Посты | Посты + видео | Команда | Агентство |
|---|---|---|---|---|
| Посты, карусели, план | ✓ | ✓ | ✓ | ✓ |
| Ролики по шаблонам, редактор | — | ✓ | ✓ | ✓ |
| Съёмка себя с суфлёром | — | ✓ | ✓ | ✓ |
| Участники, задания, входящие | — | — | ✓ | ✓ |
| Согласующий по ссылке | — | — | ✓ | ✓ |
| Проектов | 1 | 1 | 1 | до [N] |
| Публикаций в месяц | [N] | [N] | [N] | [N] на проект |
| Роликов в месяц | — | [N] | [N] | [N] на проект |
| Цена в месяц | [$] | [$] | [$] | [$] |

**3. Роли в проекте** — уже есть (ROADMAP, этап 5): редактор, участник, владелец (галочка), замещающий, согласующий (ссылка), «в кадре», «сам собирает». Плюс тестовые профили для проверки (сделано, см. ниже).

**Как это сделать в коде.** Один файл `plans.json`: тариф → функции и лимиты. В настройках проекта `mode` и `plan`. Одна проверка `can(project, feature)` в сервере, мини-приложении и боте; интерфейс прячет выключенное и говорит «доступно в тарифе …». Лимиты считаем по журналу публикаций и сборок.

**Чья подписка Claude.** Сейчас всё работает на подписке владельца бота. Для продажи нужно выбрать: (а) клиент приносит свою подписку — дешевле нам, сложнее клиенту; (б) мы держим ключи API и считаем расход в тарифе — проще клиенту, нужен учёт токенов на проект. Это решение влияет на цены, его принимаем первым.

## Новый диалоговый бот

**Почему переписываем.** Сейчас бот — прокладка к агенту: любое сообщение становится ходом Claude Code. Отсюда долгие ответы, непредсказуемый текст, нет понятных состояний диалога, дорогой расход на простые вещи. Экраны переписки на холсте («Черновик 8», A0–A12, E7, E11–E13, H7–H12) уже рисуют другой бот.

**Каким будет.**

- **Сценарии вместо свободного чата.** Каждая роль — свой набор: участник (Скинуть → «Понял так» → вопрос → «вышло», Что снять, Моё, Профиль), редактор (варианты пачкой, согласование, «не вышло», отзыв согласия), съёмка (задание → мини-приложение). Состояние диалога хранится явно: `chats/<id>.json` со сценарием и шагом.
- **Только то, что умеет Телеграм.** Кнопки под сообщением, нижняя клавиатура, команды, мини-приложение. Выбор — правкой своего сообщения, без потока ответов.
- **Нейросеть — только там, где нужна, и отвечает данными.** Разобрать материал, написать варианты, применить правку — короткий вызов Claude с ответом в JSON по схеме и проверкой. Код ролика пишет наш шаблон, а не агент; агент Claude Code остаётся для «собери что-то необычное» и режима «Про».
- **Правила общения в коде:** тихие часы, не больше 3 сообщений в день участнику, пачки для редактора, «молчание = верно».
- **Локальный Bot API** с первого дня: файлы до 2 ГБ вместо 20 МБ.

**Неделя 2 · Посты от начала до конца**
- Приём материала (A2, A3, A8, A11), варианты постов и карусели.

**Неделя 3 · Ролики по шаблонам**
- Материал → шаблон рубрики (Т1, Т2) → рендер Remotion.

**Неделя 4 · Пилот и деньги**
- Пилот у первого клиента: 3–5 постов и 1–2 ролика вместе с ним.
- Онбординг на 30 минут, инструкция на страницу, оплата (способ — [Stripe / Paddle / счёт]).
- Список правок после пилота → этап 2.

## Как проверяем: тестовые профили

В мини-приложении у владельца: Профиль › Тестовые профили. Создать профиль нужной роли (участник, «в кадре», «сам собирает», замещающий, редактор), войти под ним одной кнопкой, вернуться кнопкой «Выйти» в синей полосе сверху. «Удалить» стирает профиль и всё, что он успел сделать: его задания и записи, загруженные файлы, начатые ролики, правки текста, настройки и строки журнала. Данные настоящих людей не трогает. Боевые аккаунты клиента на тестах не используем.
