# Этапы

Каждый этап — веха на GitHub с задачами. Задача ссылается на доски холста и заканчивается проверкой.

## Этап 0 · Подготовка команды — сейчас

- Справочник проекта в `handbook/`, правила работы, шаблон pull request.
- Вехи и задачи на GitHub.
- Сервер работает из этого репозитория; выкладка одной командой.
- Приглашения соавторов в репозиторий и на холст.

**Готово, когда** новый человек со своим Claude Code за час поднимает бота и студию у себя и берёт первую задачу.

## Этап 1 · Основа: сырьё → варианты → календарь

- Бот — единый вход для сырья: фото, видео, голос, текст вперемешку; Claude раскладывает по рубрикам.
- Варианты из сырья: 2–3 поста в разных стилях + карусель, исходники рядом.
- Экран редактора «Входящие варианты»: выбрать, поправить, в очередь.
- Стили-пресеты текста (3–4).
- Очередь и календарь с событиями; Claude предлагает даты по ритму.
- Три роли: редактор, автор, ведущий; приглашения; согласия на съёмку.
- Оболочка студии: три раздела (Работа · План · Проект), чат + панель.

**Готово, когда** пилотная команда неделю публикует посты и карусели только через студию.

## Этап 2 · Рилсы и серии

- Задания ведущему «как в игре», подсказки «что снять» списком на неделю.
- Серии-шаблоны и пачки выпусков; каскад настроек с крошками в шапке выпуска.
- Корзина идей, папки-темы, где копится материал.
- Согласующий по ссылке.

## Этап 3 · Автоматика

- Автопубликация в Instagram (бизнес-аккаунт, проверка Meta).
- Статистика → выводы → правила и идеи.
- Медиатека с поиском; пробные рилсы на небольшую аудиторию.
