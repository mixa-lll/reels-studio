# Instagram: как подключить

Студия сама видит, что вышло в Instagram, и подтягивает цифры: ссылку и время выхода, обложку, подпись, лайки, комментарии, просмотры, охват и сохранения. Обновляется каждые 3 часа и по кнопке «Обновить сейчас» в Настройки › Подключения. Выкладывать по-прежнему вы — пакетом из бота.

До подключения студия работает на снимке профиля (5 ноября 2026: аватар, подписчики, 12 последних публикаций) и так и пишет: «снимок от 5 ноября».

Это делает владелец аккаунтов, один раз, минут 15. Для каждого аккаунта (@my.gudauri и @my_gudauri) — свой ключ.

## 1. Профессиональный аккаунт

В приложении Instagram, на каждом из двух аккаунтов: Настройки → «Тип аккаунта и инструменты» → «Переключиться на профессиональный аккаунт» → «Автор» или «Бизнес». Если уже профессиональный — пропустить.

## 2. Приложение в Meta

1. Зайти на [developers.facebook.com](https://developers.facebook.com) под своим Facebook и нажать «Мои приложения» → «Создать приложение».
2. Сценарий — «Управление сообщениями и контентом в Instagram» (Instagram API). Тип — «Бизнес». Название любое, например «Reels Studio».
3. В приложении: «Роли приложения» → «Роли» → «Добавить тестировщиков Instagram» → вписать `my.gudauri`, затем `my_gudauri`.
4. Принять приглашение в Instagram на каждом аккаунте: на сайте instagram.com → Настройки → «Сайты и приложения» → «Приглашения тестировщиков» → «Принять».

Facebook-страница для этого способа (вход через Instagram) не нужна. Если Meta всё же попросит её привязать — привязать страницу My Gudauri.

## 3. Ключ доступа

1. В приложении Meta: «Instagram» → «Настройка API со входом через Instagram» → «Создать маркеры доступа».
2. «Добавить аккаунт» → войти в @my.gudauri → разрешить доступ (нужны `instagram_business_basic` и `instagram_business_manage_insights`).
3. Нажать «Создать маркер» и скопировать длинную строку — это ключ.
4. Открыть студию: Настройки → Подключения → поле «Ключ доступа из Meta» → вставить → «Подключить». Через полминуты в карточке появится «подключён · обновлено только что».
5. То же для @my_gudauri.

Ключ не присылать в чат, в Телеграм и никуда больше: только в это поле. Студия проверяет его у Instagram и хранит на сервере, его не видно ни в студии, ни в логах. Ключ живёт 60 дней, студия продлевает его сама.

## Если «не обновилось»

В карточке будет причина. Чаще всего это значит, что Instagram закрыл доступ: сменили пароль или прошло больше 60 дней без продления. Создать ключ заново (шаг 3) и вставить в то же поле.

## Для разработчиков

- Код: `web/instagram.mjs`, данные — `projects/<p>/instagram/<account>/profile.json` и скачанные картинки (ссылки CDN Instagram протухают за дни).
- Ключи: файл `web/data/instagram-tokens.json` (права 600) или переменные окружения `IG_TOKEN_<АККАУНТ>`, точка — двойное подчёркивание: `IG_TOKEN_MY__GUDAURI` для my.gudauri, `IG_TOKEN_MY_GUDAURI` для my_gudauri.
- Сопоставление с выпусками: по ссылке в `items.json` (`published: [{account, url, at}]`), иначе предложение по дате, формату, языку и словам подписи — человек подтверждает «Привязать».
- Дата публикации по ссылке: шорткод в base64 (`A–Za–z0–9-_`) → id, `(id >> 23) + 1314220021721` = мс.
- Снимок без API собирается обычным посещением страницы профиля (og:-мета и картинки сетки), без закрытых эндпоинтов Instagram.
